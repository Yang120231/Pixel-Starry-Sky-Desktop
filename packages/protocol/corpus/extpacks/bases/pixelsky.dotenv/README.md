# .env 文件支持

给 `.env`、`.env.local`、`.env.production` 这类环境变量文件加上：

- **语法高亮**：注释、变量名、等号、字符串、数字、`true` / `false`、`${VAR}` 和 `$VAR` 引用、`export` 前缀、行尾注释。
- **注释切换**：Ctrl+/ 用 `#` 注释。
- **自动补全引号和括号**。
- **代码片段**：`db`（数据库连接串）、`port`、`ref`（引用另一个变量）、`section`（分节注释）。

## 已知问题

- 只有高亮，没有补全和检查（比如不会提示重复的变量名）。
- 跨多行的值（用引号包起来换行）只按第一行上色。
